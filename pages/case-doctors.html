01. CASE STUDY

医療領域
専門サイト改修

プロジェクト : ドクターズコスメ専門サイトの再定義とサイト構成の見直し

担当範囲 : UX設計 / 情報設計 / UI設計 / 実装設計 / TOPコーディング

概要

医療法人の公式サイト → 専門ページ → 通販サイトを横断し、検索流入の拡大・商品やコスメブランドの理解促進・購買導線の改善を目的としたWEB改善の事例。
通販サイトのドメインパワーの弱さや重複管理の負荷といった制約の中で、公式サイトの強い流入基盤を活かし、専門ページを「理解のハブ」、通販サイトを「購入の場」として再設計。公開後も改善を継続。

01. OVERVIEW

TARGET USER

ドクターズコスメという名前は知っているものの、 特徴や選び方までは理解していないユーザー。 来院経験がありブランドは認知しているが、 まだ積極的に購入検討していない層を主な対象とした。

CORE GOAL

専門サイトでブランドや商品の理解を深め、 通販サイトへ自然に進める導線を整えること。 専門サイトは「理解」、通販サイトは「購入」を担う形に整理した。

KPI

自然検索からの流入、 病院サイトから専門サイトへの遷移、 そして専門サイトから通販サイトへの遷移を重視した。 購入率の最適化は通販サイト側の改善と連動する前提で設計している。

MY APPROACH

当初はスマホでの読みやすさ改善が主目的だったが、 通販サイト改修と並行して見えていた課題を踏まえ、 見た目の調整ではなく、サイトの役割・情報の持ち場・導線まで見直すべきだと提案した。 この案件では、SEO会社と相談しながら提案～実装までを担当している。

02. PROBLEM

■ 目的の違う情報が同じ階層に並び、次の行動が分かりにくかった

改修前はSEO観点で情報が積み上がった結果、 ブランド理解、商品紹介、他ブランド情報などが同じ階層に混在していた。 そのため、ユーザーが「何を知るページなのか」「次に何をすればよいか」を判断しにくい状態だった。

■ 下層ページでも、内容の重複やズレが起きていた

タイトルと内容が合っていないページや、 似た内容が複数ページに分かれている箇所があり、 読んでも理解が深まりにくい状態だった。

■ 流入・理解・購入が分断されていた

通販サイトはドメインが弱く、単体での検索流入は強くなかった。 一方で、病院サイトの強いドメインを活かした専門サイトへの導線も十分ではなく、 理解してから購入へ進む流れが途切れやすい構造になっていた。

■ 運用面でも、情報を複数サイトで持つのは負担が大きかった

病院サイトは独自CMSで制約があり、 医療ガイドラインによる表現制限もある。 商品ページ数も多く更新頻度も高いため、 同じ情報を複数サイトで管理するのは現実的ではなかった。

03. THE INSIGHT

「理解」と「購入」の目的を混ぜるから複雑になる。
役割を分けて、導線でつなぐ。

問題は情報量そのものではなく、 役割の違う情報が同じ流れの中に混ざっていたことだった。 UIを少し整えるだけではなく、 まずサイトごとの役割を整理し直す必要があると判断した。

04. STRATEGIC DECISION

01. PROJECT START

当初は「読みやすさ改善」から始まった

SEO会社からは、レスポンシブ対応やスマホでの読みやすさ改善を中心とした提案が出ていた。 ただ、通販サイト改修と並行して見ていた課題を踏まえると、 表示改善だけでは根本解決にならないと感じた。

02. REFRAMING THE ISSUE

見た目ではなく、役割と導線から見直すべきだと提案

私は、専門サイトの立ち位置、情報整理、導線設計、ブランディングまで含めて見直した方が、 より価値のある改修になると提案した。 ここで、課題を「読みやすさ」から「構造設計」へ広げている。

03. DECISION MAKING

統合案：情報も購入も同一サイト内で持つ

Pros: 体験を一つにまとめやすい

Cons: CMS制約が大きく、現実的ではない

分離案：専門サイトをハブ、通販サイトを購入の場にする

Pros: 役割が明確になり、導線を整理しやすい

Cons: ドメインをまたぐ設計が必要

二重管理案：両サイトで商品情報を持つ

Pros: それぞれのサイト内で完結しやすい

Cons: 更新負荷と重複リスクが高い

04. REASONING

制約・運用・SEOのバランスからの判断

病院サイトのドメインの強さを活かし、 専門サイトを「理解のハブ」、通販サイトを「購入の場」とする方針を主導した。 また、商品詳細を両方で持つと、 内容重複や更新負荷、ガイドライン面のリスクが大きいため、 商品詳細は通販サイト側へ集約する判断をした。

一方で、SEO観点では他ブランド情報を載せる方が流入機会を広げられる面もあった。 そのため、ブランド理解に特化するUXとSEO流入のバランスは、 今後も継続して見ていくべき課題として捉えている。

05. FINAL DECISION

専門サイトは「理解」、通販サイトは「購入」。役割を分けてつなぐ構造へ

立ち位置の整理、情報量の精査、ページ構成の再設計、取捨選択、デザイン整理を主導し、 途中段階でSEO会社と上司に確認を取りながら進行。 制約がある中でも、機能する体験をつくることを目指した。

05. DESIGN STRUCTURE

目的を分けることで、迷いにくい構造にする

専門サイトでは、ブランド背景、選び方、商品一覧など 「理解を進める情報」を整理した。 一方で、購入判断に必要な詳細情報は通販サイトへ集約し、 理解するフェーズと購入するフェーズを段階的に進められるようにしている。

具体的には、専門サイトにはブランド背景や比較しやすい導線を残し、 商品詳細や購入導線は通販サイトへ渡した。 これは見せ方だけでなく、更新しやすさや責任範囲まで含めて整理した結果である。

また、病院サイトから専門サイトへの流入導線も増やし、 通販サイト単体に頼らない形で新規ユーザーを受け止められる構造を意識した。

06. UI DESIGN

情報の優先順位を整理し、理解から行動へ進めるUIに再構成

この案件では、単に整えるのではなく、 「ここで何を読ませるか」「どこで比較させるか」「いつ通販サイトへ渡すか」を明確にすることが重要だった。 その考えを、情報設計とUIの両方で揃えている。

TYPOGRAPHY & READABILITY

H1・H2・本文の差を明確にし、 長文でも読み進めやすい文字設計を行った。 医療系としての落ち着きと、美容ブランドとしての見やすさの両立を意識している。

INFORMATION PRIORITY

専門サイトでは、理解に必要な情報を優先し、 購入判断に必要な詳細情報まで持たせすぎないよう整理した。

CTA DESIGN

CTAはユーザー心理をベースに設計。例えば、理解を優先するページでは商品詳細や商品一覧に飛ぶようにし、商品一覧ページでは直接カートに入れられる機能を設置し、興味とCTAの度合いが比例するように変えている。 CTAが悪目立ちすぎないように、ボタンやバナーの見せ方も整理している。

RESPONSIVE FIRST

閲覧の多くがスマートフォンである前提から、 スマホ操作を基準にUIを設計した。 TOPは文章量を抑え、写真主体で視覚的に内容を理解しやすい入口へ再構成している。

VISUAL RESET

デザイン面では、病院サイトとしての信頼感を保ちつつ、 美容ブランドとしての新しさややわらかさも感じられるよう色設定た画像選定などを整理した。

07. IMPLEMENTATION DESIGN

TOPページのコーディングは私が担当し、 構造設計を実際の画面として成立させるベースを作った。 タグや表現についてはSEO会社の修正指示も踏まえながら調整している。

下層ページは別担当での実装になったが、 私が依頼時の説明、構造意図の共有、レイアウトやコードの確認を行い、 デザインと実装のズレが起きないよう橋渡しを担った。

また、公開後もSEOタグ改善、UI改善、導線調整を続けており、 一度作って終わりではなく、改善を回せる状態を意識している。

08. EXPECTED IMPACT & RESULTS

役割を整理することで、理解から購入へ進みやすい流れをつくる

専門サイトと通販サイトの役割を分けることで、 ユーザーが「理解 → 比較 → 購入」の流れで進みやすい状態を目指した。 情報の重複や導線の迷いを減らし、 専門サイトでは理解に集中し、必要な段階で通販サイトへ移れる構造にしている。

あわせて、情報の持ち場を整理したことで、 更新や改善の責任範囲も明確になり、 運用負荷を抑えながら改善を続けやすい状態を作れた。

UI IMPROVEMENT RESULTS

TOPページでは、文章中心で分かりにくかった構成を、 写真主体の見せ方へ変更し、入口としての役割を明確化した。 商品一覧では、ブランドサイトとしての商品紹介に特化し、 カードUIで比較しやすく整理している。

また、新たに「誕生秘話」ページを追加し、 クリニック発のコスメである背景や開発意図を伝えられるようにした。 商品理解だけでなく、共感や信頼形成にもつながる導線を意識している。

ACTUAL RESULTS

これまでのEC運用・改善施策の積み重ねにより、 参画前と比較して通販事業は約4倍規模へ成長。 本施策は、その中で見えてきた課題をもとに、 流入・理解・購入の分断を構造的に見直した改善である。

09. LEARNING

理想をそのまま作れなくても、役割設計で前に進める。

今回の施策を通して、制約のある環境でも、 役割を適切に分けて導線でつなぐことで、 ユーザー体験と事業成長の両立を目指せると実感した。

また、ページ単体の改善だけでなく、 ドメインの強さ、ガイドライン、更新負荷、関係者との連携まで含めて 構造として捉えることで、継続的に改善できる状態を作る大切さを学んだ。 今後も、こうした考え方をベースにプロダクト全体の体験設計に取り組んでいきたい。
